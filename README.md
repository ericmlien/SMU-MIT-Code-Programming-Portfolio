Each sub-directory includes a code sample from a project I'm super proud of!

Dissecare Passives and Stats (Jan 2026 - late March 2026):
    Dissecare is a 3D roguelike fps where the player replaces their body parts with appendages from enemies, stealing their abilities and passives. I designed and built the architecture for stats, actors, passives, and projectiles with scalability and easy-experimentation for designers as my main priority. Even though this project wasn't continued beyond Winter quarter, I'm still super proud of how easy it was for members of my team to experiment with the systems I built! This directory doesn't contain the whole project, only the code from it that I wrote.
GDA Godot Workshop Demo Projects (late Sept 2026 - late Nov 2026):
    As programming officer, one of my responsibilities is to craft workshops for the educational benefit of members of the club and the programming department. Trying something new this year, I added demo projects to our workshops to allow members to follow along with live-demos, making workshops more hands-on than ever before. These projects feature basic games that start unfinished and members fix and complete throughout the workshop. Each missing piece that members need to fill in corresponds to a concept taught in the workshop presentation slides. Both the projects and the slides for each workshop are linked in the directory’s README, so feel free to take a look! I'll link the slides in the google drive along with the .zip file as well.
Metapathic Entity AI and State Machines (April 2026 - early June 2026):
    Metapathic is a fast-paced, 3D platformer hack-n-slash that I helped on during Spring quarter 2026! I was tasked with planning and implementing scalable state machine and entity class structures, as well as building the foundation for npc AI behavior. Designing a system for behavior trees and building a solid foundation for characters and PvE combat was super rewarding! It was fun watching members of my team use what I built to easily turn their enemy concepts from just words on a google doc into real, intelligent, hack-n-slash-able enemies! This directory doesn't contain the whole project, only the code from it that I wrote.
